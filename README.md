# AI-MZ Dashboard

Contract management dashboard built with React, TypeScript, Vite and Tailwind CSS.

## Run it

Needs Node.js 18 or newer.

```bash
npm install
```

```bash
npm run dev
```

Then open the address it prints (usually http://localhost:5173).

## Other commands

- `npm run build`: checks the code for type errors and builds the site into `dist/`
- `npm run preview`: serves the built site locally

## Layout

- `src/AIMZDashboard.tsx`: the dashboard page
- `src/components/ui/`: small building blocks (card, button, input, tabs)
- `.mcp.json` and `.serena/`: Serena code-helper setup for Claude Code
